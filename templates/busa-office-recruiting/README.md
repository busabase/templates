# Recruiting Desk / 招聘管理

## English

Hiring positions, candidate pipelines, interviews, and reviewed offers.

Install as an independent Busabase template. Open the AirApp for overview, applicants and human attention. The native Bases provide saved working views; the included Skill supplies the agent procedure and review boundary.

### Local preview

Run npm install, npm run build:sdk and npm run dev inside content/busa-office-recruiting-app. Open ?demo=1; add &lang=zh-CN for Chinese. Demo data matches the installed samples. Screenshots prove local demo interaction, not the deployed ambient-session bridge.

### Verification

Run npm run check from this template folder and busabase-cli check . . See the repository verification report for scratch installation and deployed runtime evidence.

### Language coverage

The UI, review dialog, accessible control labels, catalog prompts, native resource and field names, specific node prompts, manual and sample narratives include English and Simplified Chinese. Native string-only metadata and example prose display both languages together. Machine values, business codes, currencies, dates and fictional personal names retain their original values. The manual provides the same workflow and restrictions in both languages.

## 简体中文

管理职位需求、候选人进度、面试反馈与录用复核。

作为独立 Busabase 模板安装。打开 AirApp 查看总览、候选人及需要人工关注的事项。原生数据表提供保存的工作视图；随附 Skill 说明 Agent 流程及复核边界。

### 本地预览

在 `content/busa-office-recruiting-app` 内执行 `npm install`、`npm run build:sdk` 及 `npm run dev`。打开带 `?demo=1` 的页面，添加 `&lang=zh-CN` 切换中文。预览示例数据与安装样本一致。演示模式截图证明本地演示交互，不代表已部署的会话连接桥接已验收。

### 验证

在本模板目录执行 `npm run check` 及 `busabase-cli check .`。专用测试安装和运行时验收证据请查阅仓库验收报告。

### 语言覆盖

界面、复核对话框、无障碍控件标签、模板卡片提示词、原生资源及字段名称、具体节点提示词、业务手册与示例叙述均包含 English / 简体中文。只接受字符串的原生元数据和示例叙述同时显示中英文。机器值、业务编号、币种、日期和虚构人物姓名保留原值。业务手册的两种语言提供相同流程和限制。
