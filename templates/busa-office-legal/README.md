# Legal Case Desk / 法务管理

Case progress, preservation deadlines, settlement evidence, and legal follow-up.

Install as an independent Busabase template. Open the AirApp for overview, cases and human attention. The native Bases provide saved working views; the included Skill supplies the agent procedure and review boundary.

## Local preview

Run npm install, npm run build:sdk and npm run dev inside content/busa-office-legal-app. Open ?demo=1; add &lang=zh-CN for Chinese. Demo data matches the installed samples. Screenshots prove local demo interaction, not the deployed ambient-session bridge.

## Verification

Run npm run check from this template folder and busabase-cli check . . See the repository verification report for scratch installation and deployed runtime evidence.
